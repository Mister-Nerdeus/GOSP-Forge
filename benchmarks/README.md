# GOSP Forge Benchmarks

Benchmarks exercise the domain-neutral challenge -> submission -> evaluation -> evidence loop.

Phase 0 begins with `sandbox-001`, a synthetic assembly-sequence problem. It intentionally avoids structural, electrical, pressure, public-health, or other safety-critical deployment claims while exercising constraints, multiple metrics, deterministic invalidation, hashing, and reproducibility.

A benchmark passing means only that the published software contract/evaluator behaved as specified for that fixture. It does not establish real-world engineering safety or certification.
