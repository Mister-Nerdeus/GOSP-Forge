# Licensing Strategy Note

This file is a planning note, not legal advice or a completed license audit.

## Phase 0 decision

The Phase 0 rebaseline does **not** change the repository's existing root license.

The GOSP Forge business plan recommends evaluating Apache-2.0 for public schemas, SDKs, conformance tests, and reference adapters because of its permissive terms and express patent grant. That recommendation should be reviewed deliberately before the project changes license or introduces mixed licensing.

## Contribution rule

Do not copy source code, CAD, models, textures, datasets, standards text, or manufacturer assets merely because they are publicly accessible.

For every material third-party dependency or asset, record:

- source and version;
- governing license/terms;
- modifications;
- distribution mode;
- notices/source obligations;
- responsible maintainer/owner;
- security/support status when relevant.

Reciprocal GPL/AGPL/MPL/LGPL dependencies require deliberate architecture and legal review rather than assumptions based on process separation.
