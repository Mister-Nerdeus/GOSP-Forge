# ADR 0002: Reproducibility before Forge Studio

- Status: Accepted for Phase 0
- Date: 2026-08-06

## Decision

The project will prove challenge contracts, deterministic evaluation, hashing, and evidence capture before investing in the production 2D/3D Forge Studio experience.

## Rationale

A polished editor can demonstrate a vertical, but it does not prove the GOSP Forge differentiator: a trustworthy chain from challenge definition through reproducible evaluation to auditable evidence and reusable release metadata.

## Consequences

- Phase 0 uses a simple synthetic benchmark.
- Browser 3D remains a subsequent phase.
- Pascal, Three.js, IFC, EnergyPlus, and related integrations are not Phase 0 dependencies.
